Capstone Project for the course. 
It's a Flash Card app for learning french, the csv file contains 100 words, it'll show you a word in french and it's pair in english. 
If you know the word, you press the Checkmark button and it gets deleted from the list, and it'll show you a new word. 
If you don't know the word, you press the X button, and it gives you a new word, without deleting anything from the list, so you can practice the word later again
